# Email Builder

A staff tool for Mathnasium centers. Upload assessment PDFs exported from Radius and it drafts the parent email. Everything runs in the browser. Nothing is uploaded.

- Live page: published from this repo with GitHub Pages.
- Updating it: see `HOW_TO_UPDATE.md`.
- Working on it with AI: see `CLAUDE.md`.
- Tests: see `tests/README.md`.

This repo is public. Never add student PDFs, names, or screenshots.
